# Bochi

Bochi is a language exchange web app for two partners learning together: Japanese practice for Bolu (Boru-san) and English practice for Chihiro-san.

It includes chapter-based lessons from the ground up, character, word and phrase practice, two-player session games, a review queue for missed items, progress journeys for both partners, and session booking.

Live at https://bochi.bolu.tech
